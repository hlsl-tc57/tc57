\Ch{SIMT Functions}{SIMT}

\p This clause lists and describes functions provided by the HLSL standard
library to perform operations utilizing the \acrshort{simt} programming model to
coordinate across co-executing threads. These operations are called
\textit{cooperative} and require execution synchronization.

\p The set of cooperative functions are divided into functions that require
cooperation of the variable-width \gls{wave} called \textit{wave functions}
(\ref{SIMT.Wave}), and functions that require cooperation of groupings of four
adjacent threads called \textit{quad functions} (\ref{SIMT.Quad}).

\p The full semantics of \acrshort{simt} cooperation is detailed in the
execution model (\ref{Basic.Exec}).

\Sec{Wave Functions}{SIMT.Wave}

\p This subclause defines the set of \gls{wave} functions included in the
HLSL standard library.

\Sub{Other Non-Member Functions}{SIMT.Wave.Functions.Other}

\begin{HLSL}
bool WaveIsFirstLane();
\end{HLSL}

\begin{itemize}
  \item \textit{Synchronization:} all co-executing threads within a \gls{tangle}
  must complete evaluation of all preceding expressions and sub-expressions
  prior to evaluating this function.
  \item \textit{Returns:} \texttt{true} only on the \gls{lane} with the
  lowest index in the \gls{tangle}; \texttt{false} on all other lanes.
\end{itemize}

\begin{HLSL}

\end{HLSL}

\begin{itemize}

\begin{HLSL}
template <typename T> bool WaveActiveAllEqual(T value);
\end{HLSL}

\begin{itemize}
  \item \textit{Synchronization:} all co-executing threads within a \gls{tangle}
  must complete evaluation of all preceding expressions and sub-expressions
  prior to evaluating this function.
  \item \textit{Returns:} returns \texttt{true} if \texttt{value} in all threads
  equates to the same value as if \texttt{value\textsubscript{0} ==
  value\textsubscript{1} \&\& value\textsubscript{1} == value\textsubscript{2}
  \&\& ...}; \texttt{false} otherwise.
  \item \textit{Remarks:} the return value of this function is uniform across
  the \gls{tangle}.
\end{itemize}

\begin{HLSL}
vector<uint, 4> WaveActiveBallot(bool cond);
\end{HLSL}

\begin{itemize}
  \item \textit{Synchronization:} all co-executing threads within a \gls{tangle}
  must complete evaluation of all preceding expressions and sub-expressions
  prior to evaluating this function.
  \item \textit{Returns:} A 128-bit bitmask stored in a \texttt{vector<uint,
  4>}, where each bit denotes if \texttt{cond} on the corresponding \gls{lane}
  was \texttt{true} with a \texttt{1} and is otherwise \texttt{0}. The least
  significant bit stores the value from the \gls{lane} with index zero, and the
  more significant bits map to \gls{lane}s in increasing index order. Any bits
  that do not map to \gls{lane}s in this \gls{wave} or map to inactive
  \gls{lane}s are \texttt{0}.
  \item \textit{Remarks:} the return value of this function is uniform across
  the \gls{tangle}.
  \item \textit{Notes:} The 128-bit bitmask has one bit for each \gls{lane} in
  the maximum \gls{wave} size.
\end{itemize}

\begin{HLSL}
template <typename T> T WaveReadLaneAt(T value, uint lane);
\end{HLSL}

\begin{itemize}
  \item \textit{Synchronization:} all co-executing threads within a \gls{tangle}
  must complete evaluation of all preceding expressions and sub-expressions
  prior to evaluating this function.
  \item \textit{Returns:} the value of \texttt{value} from the \gls{lane}
  specified by \texttt{lane}.
  \item \textit{Remarks:} the return value of this function is uniform across
  the \gls{tangle} if \texttt{lane} is uniform.
\end{itemize}

\p This subclause defines the set of \gls{quad} functions included in the
HLSL standard library.

\p Co-executing threads within a \gls{wave} are logically subdivided into a quad
grouping comprised of four threads numbered $0..3$. The indices correspond to a
logical layout which maps the layout of pixels in a pixel shader as illustrated
in the table below:

\begin{center}
  \begin{tabular}{| c | c |}
    \hline 0 & 1 \\
    \hline 2 & 3 \\
    \hline
  \end{tabular}
\end{center}

\p In the operations in this subclause $X$ refers to the horizontal axis in the
table above while $Y$ refers to the vertical axis.
