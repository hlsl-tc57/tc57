\Ch{Mathematics Functions}{Math}

\p This clause lists and describes functions provided by the HLSL standard
library to work with numeric data and perform mathematical operations.

\Sub{Arithmetic Typedefs}{Math.Types}

\p This subclause lists the arithmetic typedefs that are provided for users and
their definitions.

\begin{HLSL}
#if sizeof(short) == 2
// 16-bit integer.
typedef unsigned short uint16_t;
typedef short int16_t;
#endif

#if sizeof(half) == 2
// 16-bit floating point.
typedef half float16_t;
#endif

// 32-bit integer.
typedef int int32_t;

// unsigned 32-bit integer.
typedef unsigned int uint;
typedef unsigned int uint32_t;

// 32-bit floating point.
typedef float float32_t;

// 64-bit integer.
typedef unsigned long uint64_t;
typedef long int64_t;

// 64-bit floating point
typedef double float64_t;
\end{HLSL}

\p The explicitly sized 16-bit types are only defined if the compiler supports
16-bit native types are supported.
